# sci-image-markdown

Scientific document and image processing pipeline to structured Markdown.

## Overview

`sci-image-markdown` is a research and engineering pipeline designed to convert scientific images, charts, and complex document layouts into structured Markdown representations.

## Structure

- `AGENTS.md`: Agent workflows, skills, and issue tracking protocols.
- `docs/`: Architecture Decision Records (ADRs), domain models, and agent documentation.
- `docs/agents/`: Tooling guidelines, triage definitions, and issue tracker specifications.
